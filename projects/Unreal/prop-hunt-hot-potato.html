Project Overview

Prop Hunt (Hot Potato) is a unique take on the classic hide-and-seek genre. Built with Unreal Engine 5 and C++, it introduces a "Hot Potato" mechanic where roles can switch dynamically mid-round, forcing players to adapt their strategies instantly. The project focuses heavily on robust LAN networking and modular gameplay systems.

Key Features

Dynamic Role Switching: Implemented a "Hot Potato" system that transfers the hunter role between players based on gameplay events.
Prop Transformation System: Developed a flexible system for players to transform into various environmental actors while maintaining networked synchronization.
LAN Multiplayer Networking: Set up a robust LAN-based session system using Unreal's Online Subsystem for low-latency local play.
System-Driven Gameplay: Focused on decoupled C++ logic to manage game states, timers, and player scoring.

Technical Responsibilities
